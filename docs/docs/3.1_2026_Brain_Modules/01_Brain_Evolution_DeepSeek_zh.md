# 人类大脑从简单生物到现代人的进化：新增模块与计算功能

本文档按照进化顺序，列出从最简单的神经系统到人类大脑，每一次关键进化中**新增**的脑模块及其功能。

- 生物1: 单细胞生物与早期多细胞生物 (e.g., 草履虫, 海绵)
    - **无神经元**，仅有细胞内信号传导或非常原始的神经样细胞。

- 生物2: 刺胞动物 (Cnidarians, e.g., 水螅, 水母)
    - **神经网 (Nerve Net)**
        - 前身: 无（最早出现的神经系统）
        - 输入: 机械刺激、化学信号（猎物/危险）、光（简单感光）
        - 输出: 全身肌肉收缩（捕食、逃避）、消化腔收缩
        - 计算功能: **全息式反射** - 任何位置的输入触发全局输出，无方向性行为模式

- 生物3: 扁形动物 (Flatworms, e.g., 涡虫)
    - **脑 ganglions (头部神经节 / Cerebral Ganglia)**
        - 前身: 神经网
        - 输入: 眼点（光方向）、化学梯度（食物）、触觉
        - 输出: 运动控制（纵向肌肉）、转向行为
        - 计算功能: **侧向抑制 + 趋性计算** - 比较左右两侧输入强度，实现趋光/趋化转向
    - **纵贯神经索 (Longitudinal Nerve Cords)**
        - 前身: 神经网局部集中
        - 输入: 来自头部神经节的运动指令
        - 输出: 身体节段肌肉
        - 计算功能: **信号中继与协调** - 将头部决策信号传导至全身，实现爬行中的体节协调

- 生物4: 环节动物 (Annelids, e.g., 蚯蚓)
    - **咽下神经节 (Subpharyngeal Ganglion)**
        - 前身: 神经索局部膨大
        - 输入: 来自头部神经节的感觉信号、身体前部触觉
        - 输出: 口部/咽部肌肉
        - 计算功能: **局部摄食反射弧** - 独立于头部处理“吞咽/拒绝”决策
    - **体节神经节 (Segmental Ganglia)**
        - 前身: 纵贯神经索的重复单元
        - 输入: 本节的机械/化学感受器、相邻神经节的信号
        - 输出: 本节体壁肌肉、刚毛
        - 计算功能: **节间反射协调** - 实现蠕动的递进式收缩波（例如：抑制前节收缩，兴奋后节收缩）

- 生物5: 节肢动物 (Arthropods, e.g., 昆虫)
    - **蕈形体 (Mushroom Bodies)**
        - 前身: 前脑嗅觉区
        - 输入: 嗅觉感觉神经元（触角）、多巴胺能奖励/惩罚信号
        - 输出: 运动输出指令（趋避行为）
        - 计算功能: **联想学习与情景记忆编码** - 将气味与结果关联（经典条件反射），形成短时和长时记忆
    - **中央复合体 (Central Complex)**
        - 前身: 前脑中间体
        - 输入: 视觉（复眼偏振光/天空模式）、本体感觉、头部朝向信息
        - 输出: 导航相关的运动指令
        - 计算功能: **航向计算与路径整合** - 结合视觉地标与自身运动，实现空间定位（类似内部罗盘）

- 生物6: 头足类软体动物 (Cephalopods, e.g., 章鱼)
    - **垂直叶 (Vertical Lobe)**
        - 前身: 视觉学习相关区域
        - 输入: 视觉（形状、纹理）、触觉、痛觉
        - 输出: 触手运动选择
        - 计算功能: **视觉与触觉模式的短期记忆与分类** - 快速学习“可食/不可食”形状，并维持记忆数小时
    - **视叶 (Optic Lobes) 的精细化**
        - 前身: 原始视觉处理区
        - 输入: 视网膜图像
        - 输出: 物体识别信号（至垂直叶）
        - 计算功能: **形状与纹理的特征提取** - 提取边缘、方向、对比度，为学习提供高维输入

- 生物7: 脊椎动物早期 (Early Vertebrates, e.g., 七鳃鳗)
    - **菱脑 (Rhombencephalon / Hindbrain)**
        - 前身: 神经管后部
        - 输入: 听觉/平衡（前庭）、内脏感觉、脊髓上行信号
        - 输出: 运动指令（经脊髓）、呼吸节律
        - 计算功能: **节律生成与基本生命支持** - 产生呼吸、心跳节律；控制吞咽、逃避反射（快速转向）
    - **中脑 (Mesencephalon / Midbrain)**
        - 前身: 神经管中部
        - 输入: 视觉（顶盖）、听觉、本体感觉
        - 输出: 眼动指令、身体转向指令
        - 计算功能: **感觉-运动转换与空间定位** - 将视觉/听觉空间位置映射到运动方向（例如：看到猎物位置 → 向该处转头/转身）
    - **间脑 (Diencephalon)**
        - 前身: 神经管前部
        - 输入: 所有感觉的汇聚（除嗅觉）、体温、血糖、渗透压
        - 输出: 激素（垂体）、自主神经调节、对皮层的调制
        - 计算功能: **内稳态调节与感觉中继** - 下丘脑调节进食/饮水/体温；丘脑作为感觉信号通往端脑的闸门

- 生物8: 硬骨鱼 (Bony Fish)
    - **小脑体 (Corpus Cerebelli)**
        - 前身: 菱脑背侧膨大
        - 输入: 脊髓（本体感觉/触觉）、前庭系统、视觉运动信息
        - 输出: 运动纠正信号（至中脑/脊髓）
        - 计算功能: **运动协调与适应性学习** - 比较预期运动与实际运动（前馈控制），优化游泳姿态和平衡
    - **基底端脑 (Basal Telencephalon)**
        - 前身: 前脑腹侧
        - 输入: 嗅觉、中脑边缘信号（奖励）
        - 输出: 对运动系统的抑制/去抑制
        - 计算功能: **奖惩驱动的行为选择** - 早期基底节功能，选择“趋近”或“回避”

- 生物9: 两栖动物 (Amphibians, e.g., 青蛙)
    - **顶盖的层状化 (Laminated Optic Tectum)**
        - 前身: 中脑顶盖（单层）
        - 输入: 视网膜（对向映射）
        - 输出: 猎物/捕食者识别信号
        - 计算功能: **小物体检测与运动方向选择性** - 识别“虫状”运动物体，忽略大范围运动（自我运动过滤）
    - **原始大脑皮层 (Primordial General Cortex / 背侧端脑)**
        - 前身: 嗅皮层前方薄层
        - 输入: 来自丘脑的嗅觉、视觉、听觉（粗）
        - 输出: 行为抑制/启动信号（至基底节）
        - 计算功能: **多感觉粗分类** - 简单区分“安全/危险”场景，存储长达数天的恐惧记忆

- 生物10: 爬行动物 (Reptiles)
    - **背侧室嵴 (Dorsal Ventricular Ridge, DVR)**
        - 前身: 端脑背侧膨大（非哺乳类特有）
        - 输入: 视觉、听觉（精细）
        - 输出: 感官分类信号（至基底节）
        - 计算功能: **感觉模式的绝对识别** - 识别特定形状、声音（例如：捕食者轮廓），不依赖上下文
    - **内侧皮层 / 海马原基 (Medial Cortex / Hippocampal Primordium)**
        - 前身: 两栖类背侧端脑
        - 输入: 空间视觉、本体感觉
        - 输出: 空间记忆信号
        - 计算功能: **认知地图的雏形** - 编码场所与地标的相对位置，用于巢穴定位、领地巡逻

- 生物11: 早期哺乳动物 (Early Mammals, e.g., 鼩鼱)
    - **新皮层 (Neocortex, 六层结构)**
        - 前身: 爬行动物背侧皮层（三层）
        - 输入: 丘脑（所有感觉）、海马、基底节、脑干调制核团
        - 输出: 精细运动指令（经皮层脊髓束）、感觉分类、记忆编码
        - 计算功能: **感觉维度重组与长程关联** - 实现跨感觉模态的抽象（例如：看到+听到+闻到同一个物体），支持类别形成和灵活泛化
    - **海马齿状回与CA区 (Dentate Gyrus & CA fields)**
        - 前身: 爬行动物内侧皮层
        - 输入: 内嗅皮层（高度处理过的感觉）、新皮层
        - 输出: 记忆印迹编码（至新皮层）
        - 计算功能: **情景记忆的单次学习与模式分离** - 将不同时空事件的表征正交化，避免记忆干扰
    - **丘脑网状核 (Thalamic Reticular Nucleus)**
        - 前身: 丘脑外周的散在神经元
        - 输入: 皮层-丘脑投射的拷贝
        - 输出: 抑制丘脑-皮层投射
        - 计算功能: **注意力门控** - 选择性增强部分感觉传入，抑制无关信息（节律性发放控制注意力窗）

- 生物12: 灵长类早期 (Early Primates)
    - **视觉皮层V4与IT (V4 & Inferotemporal Cortex)**
        - 前身: 新皮层次级视觉区
        - 输入: V2/V3（线条方向、颜色）
        - 输出: 复杂形状/面部特征信号
        - 计算功能: **颜色恒常性与中层形状编码** - 提取圆形、椭圆形、面部局部特征（眼睛、嘴），实现部分遮挡下的物体识别
    - **前额叶皮层背外侧部 (DLPFC, 初现)**
        - 前身: 运动前区前方
        - 输入: 多感觉皮层（顶叶、颞叶）、杏仁核
        - 输出: 运动前区指令
        - 计算功能: **工作记忆与规则编码** - 在几秒到几十秒内维持信息（延迟反应任务），实现“如果-那么”规则

- 生物13: 早期人科 (Hominins, e.g., 能人)
    - **Broca区原基 (Broca’s Area Homolog, BA44/45)**
        - 前身: 运动前区腹侧 (F5 in monkey)
        - 输入: 听觉（声音序列）、顶叶（手势）、颞叶（语义）
        - 输出: 口面部运动指令、喉部控制
        - 计算功能: **序列动作的语法化** - 将手势/声音按层级结构组合（非随机序列），支持原始工具制作和基本发音
    - **角回的扩大 (Angular Gyrus expansion)**
        - 前身: 顶叶下小叶
        - 输入: 视觉、听觉、躯体感觉
        - 输出: 跨模态整合信号至颞叶/额叶
        - 计算功能: **符号化与抽象数量感** - 将非符号数量（两个苹果）映射到符号（“2”），支持原始计数和语言理解

- 生物14: 现代人类 (Homo sapiens)
    - **前额叶皮层极区 (Frontopolar Cortex, BA10)**
        - 前身: 灵长类DLPFC的前方区域
        - 输入: 来自DLPFC、ACC、顶叶、颞极的高度整合信号
        - 输出: 对DLPFC的偏置信号、对其他前额叶子区的调控
        - 计算功能: **多分支心智模拟与推理** - 同时维护两个以上可能的未来场景，进行因果比较（“如果A且B，则C vs D”），支持计划、反事实思考和元认知
    - **外侧前额叶的精细颗粒层 (Granular Layer in lateral PFC)**
        - 前身: 灵长类的无颗粒区
        - 输入: 多模态感觉、长时记忆检索
        - 输出: 抑制/兴奋其他皮层
        - 计算功能: **认知控制与任务切换** - 根据内部目标抑制自动反应（Stroop任务、延迟满足），灵活切换行为策略
    - **人类特有FOXP2调控下的基底节-皮层环路细化 (Basal ganglia-thalamocortical loops refinement)**
        - 前身: 哺乳类运动/认知环路
        - 输入: 听觉语音、口面部感觉
        - 输出: 精细发音序列
        - 计算功能: **快速语音序列学习与自动化** - 支持复杂音节组合（每秒10-15个音素），实现流畅的语法化语言产出
